# Privacy Policy — Explain This

**Last updated:** 31 July 2026

## Short version

Explain This collects nothing, stores nothing, and sends nothing anywhere.

## What the extension reads

When you select text and ask for an explanation, the extension reads:

- the text you selected
- the paragraphs immediately around it, the nearest heading, the page title, and the page address
- with **Explain deeper**, the main body of the article you're on

## What happens to it

It is passed to the AI model built into Chrome, which runs on your own computer, and is used only to produce the explanation you asked for. It is held in memory for the length of that one request and then discarded.

The extension makes no network requests. There is no server behind it, no account to create, and no analytics, telemetry, error reporting, or advertising of any kind. Nothing is written to disk. Nothing is shared with the developer or with any third party, because nothing ever leaves your browser.

## Permissions

The extension requests no Chrome permissions.

It does run on any page you visit, which it needs in order to notice text you have selected. That access is used for nothing else.

## The model

The explanation is produced by Chrome's built-in on-device model. Chrome downloads and manages that model itself; the extension only asks it questions. Chrome's own handling of it is covered by [Google Chrome's privacy notice](https://www.google.com/chrome/privacy/).

## Changes

Any change to this policy will be committed to [this repository](https://github.com/Vishruth-Sham/explain-this), where its history is public.
